# EduPlan
Plataforma para organizar y priorizar la carga académica universitaria (React + TanStack Start + Tailwind).

## Cómo ejecutar
1. Instala Node 20+ y bun (o npm).
2. `bun install` (o `npm install`)
3. `bun run dev` y abre http://localhost:8080
4. Para producción: `bun run build`

Funciones: panel con prioridad sugerida, calendario, alertas, carga semanal, trabajos grupales. Los datos se guardan en el navegador.
